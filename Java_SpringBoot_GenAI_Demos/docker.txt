docker volume

 
==================================================

DOCKER CONTAINER WITH VOLUME VS WITHOUT VOLUME

==================================================
 
 
INTRODUCTION

=================================
 
Docker Container stores application files, logs and database data.
 
There are two ways:
 
1 ===== Without Volume

2 ===== With Volume
 
 
 
=================================

WITHOUT VOLUME

=================================
 
Create Container:
 
Docker pull mysql:8.0
 
Docker run -d --name mysql-db -e MYSQL_ROOT_PASSWORD=root mysql:8.0
 
 
What Happens?
 
Data is stored inside container.
 
 
Examples:
 
Database Tables

Employee Records

Logs

Uploaded Files
 
 
 
=================================

PROBLEM WITHOUT VOLUME

=================================
 
Create Table:
 
 
CREATE TABLE employee(

id INT,

name VARCHAR(50)

);
 
 
Insert Record:
 
INSERT INTO employee VALUES(1,'Sunil');
 
 
Delete Container:
 
docker rm -f mysql-db
 
 
Create Container Again:
 
docker run -d --name mysql-db mysql:8.0
 
 
Result:
 
Employee Table Missing

Data Lost
 
 
 
 
=================================

WITH VOLUME

=================================
 
Step 1 ===== Create Volume
 
Command:
 
docker volume create mysql-data
 
 
Verify:
 
docker volume ls
 
 
Step 2 ===== Attach Volume
 
Command:
 
docker run -d --name mysql-db -e MYSQL_ROOT_PASSWORD=root -v mysql-data:/var/lib/mysql mysql:8.0
 
 
 
=================================

HOW VOLUME WORKS

=================================
 
 
Container ===== Temporary
 
Volume ===== Permanent Storage
 
Database Files ===== Stored in Volume
 
Container Removed ===== Data Safe
 
 
 
 
=================================

  MYSQL EXAMPLE

=================================
 
 
Create Volume:
 
docker volume create mysql-data
 
 
Run Container:
 
docker run -d --name mysql-db -e MYSQL_ROOT_PASSWORD=root -e MYSQL_DATABASE=mydb -e MYSQL_USER=myuser -e MYSQL_PASSWORD=root -v mysql-data:/var/lib/mysql mysql:8.0
 
 
Create Table and Insert Data.
 
 
Delete Container:
 
docker rm -f mysql-db
 
 
Recreate Container:
 
docker run -d --name mysql-db -e MYSQL_ROOT_PASSWORD=root -v mysql-data:/var/lib/mysql mysql:8.0
 
 
Result:
 
Data Still Available
 
 
 
 
=================================

SPRING BOOT EXAMPLE

=================================
 
 
WITHOUT VOLUME
 
Docker run -d --name app -p 8081:8081 myapp:latest
 
Uploaded Files Lost After Container Deletion.
 
 
WITH VOLUME
 
Docker run -d --name app -p 8081:8081 -v app-data:/app/uploads myapp:latest
 
Uploaded Files Remain Safe.
 
 
 
=================================

COMMANDS

=================================
 
Create Volume
 
docker volume create mysql-data
 
 
List Volumes
 
docker volume ls
 
 
Inspect Volume
 
docker volume inspect mysql-data
 
 
Remove Volume
 
docker volume rm mysql-data
 
 
=====================================================================
 
 
Q1: Why use Docker Volume?
 
Answer:
 
Volume provides persistent storage.
 
 
Q2: What happens if container is deleted?
 
Without Volume ===== Data Deleted
 
With Volume ===== Data Retained
 
 
Q3: Where is MySQL data stored?
 
Without Volume ===== Container Filesystem
 
With Volume ===== Docker Volume
 
 
Without Volume ===== Container Deleted = Data Deleted
 
With Volume ===== Container Deleted = Data Safe

Volumes:====================================================================================================
 
 
=================================

DOCKER WITH VOLUME VS WITHOUT VOLUME

=================================
 
 
WITHOUT VOLUME

=================================
 
docker run -d --name mysql-db mysql:8.0
 
Data is stored inside the container.
 
If container is deleted:
 
docker rm -f mysql-db
 
Result:

Data is lost.
 
 
=================================

WITH VOLUME

=================================
 
Create Volume:
 
docker volume create mysql-data
 
Run Container:
 
docker run -d --name mysql-db -v mysql-data:/var/lib/mysql mysql:8.0
 
Result:

Data is stored in volume.
 
If container is deleted:
 
docker rm -f mysql-db
 
Data remains available.
 
 
 
=================================

COMPARISON

=================================
 
Without Volume ===== Data Deleted
 
With Volume ===== Data Retained
 
Container ===== Temporary
 
Volume ===== Persistent Storage
 
 
 
 
=================================

REAL TIME MYSQL EXAMPLE

=================================
 
Create Volume:
 
docker volume create mysql-data
 
Run MySQL:
 
docker run -d --name mysql-db -e MYSQL_ROOT_PASSWORD=root -v mysql-data:/var/lib/mysql mysql:8.0

Why use Docker Volumes?
 
Answer:

Volumes provide persistent storage and prevent data loss when containers are deleted.
